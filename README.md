# gprawl
Gynia Prawl's Senior Capstone Project: ThreatWatch CyberLab

What the Project Does:
  ThreatWatch is a gamified cybersecurity learning platform that simulates common cyber threats, such as network intrusions, host-based attacks, and password cracking, and shows how an Intrusion Detection System (IDS) detects and responds to them.

Why the Project is Useful:
  The project helps users learn cybersecurity concepts through hands-on, interactive scenarios instead of theory alone. It makes intrusion detection easier to understand, especially for students and beginners.
